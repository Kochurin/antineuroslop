# Политика конфиденциальности

Антинейрослоп разбирает текст прямо в вашей вкладке. Расширение не отправляет текст, адреса страниц и любые другие данные ни на какой сервер, не использует аналитику и не показывает рекламу на сайтах

В локальном хранилище браузера (`chrome.storage.local`) расширение держит только свои настройки: включено ли оно, на каких сайтах выключено, какие правила вы отключили, черновик из окна разбора и скрыт ли блок автора. Эти данные не покидают ваш компьютер и удаляются вместе с расширением

Разрешение `activeTab` нужно, чтобы окно расширения показало адрес текущего сайта для переключателя «на этом сайте»

В окне расширения есть блок со ссылками на SkyrimVPN, проект автора. Ссылки открываются только по вашему клику, блок скрывается крестиком

Вопросы: https://github.com/Kochurin/antineuroslop/issues

---

**Privacy policy (English).** Antineuroslop analyzes text locally in your tab. It sends no text, URLs or other data to any server and has no analytics. It stores only its own settings in `chrome.storage.local`. The popup contains a dismissible block with links to SkyrimVPN, the author's project; the links open only when you click them
